# 网站语言与排版

中文是内容原文。更新文案时先修改 `src/messages.js` 中的 `zh`，再同步英文与 `src/locales/` 中的七个语言文件，保留专名、创始人身份、项目开发状态及原文的含义与语气。新增译文经过语义与页面复核，尚未经过独立母语审校。

语言菜单顺序固定为：简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、العربية。新访客默认简体中文；有效的 `?lang=` 参数优先于本机保存的语言。没有参数时读取已保存选择，存储不可用时仍能通过URL切换。站内跳转、新标签打开、刷新和浏览器返回均保留URL中的语言。

示例：`/?lang=ja`、`/about?lang=ar`、`/games/baishishu?lang=zh-Hant`。云笺应用与外部网站保持各自现有语言能力；本次不改动这些独立应用。

九种语言覆盖主站首页、AI产品、游戏目录、两款游戏介绍、书籍、关于与支持页，以及导航、页脚、按钮、替代文字和运行时页面描述。静态HTML仍以中文输出，页面脚本按所选语言更新标题和描述；不把这次改动描述成九语言静态SEO页面。

## 字体与响应式

繁体、日文、韩文分别使用Noto Serif TC、JP、KR；阿拉伯文使用Noto Naskh Arabic，拉丁语种使用Source Serif 4和Source Sans 3。网站自托管所用字体，保留对应OFL许可；字符子集覆盖全部九种语言文案与菜单。西语重音字母、ñ及标点已核对字体字符表，无需增加字体下载。

语言选择控件和每个选项都带有明确的语言标记，按语言指定对应字体并固定400字重，禁用合成字重。简中四字均使用Noto Serif SC，繁中、日文、韩文和阿拉伯文使用各自的字体；英文、西语、法语、德语使用Source Sans 3。避免已选语言继承其他语种的字体或跨字体拼字。

语言名称前显示灰绿色细线翻译图标，图标包含在原生选择框的点击范围内，辅助技术只读取控件的语言标签。九种语言共用该入口，保留44px点击高度。

社交链接顺序为X、LinkedIn、GitHub、Telegram，分隔线后为Instagram、Facebook、TikTok。Telegram使用 `https://t.me/shixilin`，同时出现在页脚和关于页。手机按可用宽度缩小图标间距，保留图标尺寸。

阿拉伯语页面使用 `dir="rtl"`，邮件、域名、钱包地址、产品名称与中文书名保持各自的字符顺序。日文标题使用语义短语保护，韩文按词换行。长标题、按钮和首屏随内容撑开；游戏资料栏随可用宽度换列。

云笺印记是九种语言共有的中文品牌标记，均显示“云笺”。两个汉字分为独立行，固定字体、行高和字距，在金色边框中居中；印记跟随介绍文字下沿定位。此前八语种在1440、768、390和320px宽度下的32组检查确认印记可见、文字在框内、边框在云图内。西语保持相同组件和竖排印记。

关于页联系邮箱为18px，620px及以下为17px，箭头14px。保留至少44px高的点击区域，12组简中、英文与阿拉伯文视口检查通过。关于页首段在所有尺寸下采用上下排列：名字、英文名与身份组成一组，下接主张和介绍；统一按阅读方向对齐，阿拉伯文右对齐，其余语言左对齐。介绍区最大宽度760px，正文最大宽度650px；桌面组间距36px，900px及以下32px。
