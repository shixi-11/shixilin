# 网站语言与排版

中文是内容原文。更新文案时先修改 `src/messages.js` 中的 `zh`，再同步英文与 `src/locales/` 中的六个语言文件，保留专名、创始人身份、项目开发状态及原文的含义与语气。新增译文经过语义与页面复核，尚未经过独立母语审校。

语言菜单顺序固定为：简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、العربية。新访客默认简体中文；有效的 `?lang=` 参数优先于本机保存的语言。没有参数时读取已保存选择，存储不可用时仍能通过URL切换。站内跳转、新标签打开、刷新和浏览器返回均保留URL中的语言。

示例：`/?lang=ja`、`/about?lang=ar`、`/games/baishishu?lang=zh-Hant`。云笺应用与外部网站保持各自现有语言能力；本次不改动这些独立应用。

八种语言覆盖主站首页、AI产品、游戏目录、两款游戏介绍、书籍、关于与支持页，以及导航、页脚、按钮、替代文字和运行时页面描述。静态HTML仍以中文输出，页面脚本按所选语言更新标题和描述；不把这次改动描述成八语言静态SEO页面。

## 内容口径

- 首页保留“在技术与人文之间，寻找安静的连接。”“写诗词与小说，也做AI产品和独立游戏。”
- 墨核标识为 `AI Pet · Codex Pet`；中文介绍为“住在你电脑里的小小守护者，安静陪伴，偶尔调皮。”英文指代继续使用 `it / its`。产品页补充Codex Pet与独立Windows桌面版的区别。
- 十一資本排在企业与项目首位，中文名称保留“資”。ALUX、Foundation ALUX与ConcurSys的联合创始人身份保留。
- 书名与品牌专名不擅自创作新的官方译名；社交账号保留 `@光之十一`。
- 游戏美术继续使用已确认资产，本次未替换封面或修改位图。

## 字体与响应式

繁体、日文、韩文分别使用Noto Serif TC、JP、KR；阿拉伯文使用Noto Naskh Arabic，拉丁语种使用Source Serif 4和Source Sans 3。网站自托管所用字体，保留对应OFL许可；字符子集覆盖全部八种语言文案与菜单。

阿拉伯语页面使用 `dir="rtl"`，邮件、域名、钱包地址、产品名称与中文书名保持各自的字符顺序。日文标题使用语义短语保护，韩文按词换行。长标题、按钮和首屏随内容撑开；游戏资料栏随可用宽度换列。
