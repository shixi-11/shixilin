## 视觉方向

保留圆形竖排“十一”标志、中文姓名与英文副标。温白纸色、淡彩山水、灰墨文字和旧金细线构成全站基调。首页图文以正常网页阅读尺度展开，手机改为单列，小舟完整出现在首屏山水中。

字体使用Noto Serif SC、Source Sans 3和Source Serif 4。英文正文与标题使用Source Serif 4，避免中文字体替代英文弯引号和标点时破坏字面节奏。字体随站点提供，许可证保存在public/fonts；Source Serif 4保持官方字体原文件，中文与辅助字体按现役文案更新子集。
